# Cyber Win — Endterm

Учебный сайт на HTML, CSS, Bootstrap, JavaScript и jQuery. Проект продолжает
midterm: сохраняет пять страниц, навигацию и адаптивную сетку. Все данные
демонстрационные, настоящей авторизации, платежей и ставок нет.

Сайт: https://twinterrorss.github.io/web-endterm/

## Запуск

В папке проекта выполните:

```bash
python -m http.server 8000
```

Откройте http://localhost:8000/profile.html. Сборка и установка npm-пакетов не нужны.
Для Sports и Live Casino нужен интернет: jQuery подключается с `code.jquery.com`.
Открывайте все страницы на одном адресе и порту, чтобы у них был общий localStorage.
Локальная и опубликованная версии хранят данные отдельно.

## Часть Muba

- **Edit Profile:** форма имени, email и страны. JavaScript проверяет имя
  длиной 3–60 символов, email длиной до 100 символов и выбор страны.
  Ошибки появляются под полями, первое неверное поле получает фокус.
  После сохранения данные обновляются без перезагрузки. Cancel отменяет ввод.
- **Light mode / Dark mode:** кнопка в шапке каждой страницы меняет
  `data-bs-theme` и CSS-переменные. Выбор сохраняется между страницами и
  обновляется в других открытых вкладках того же сайта.
- **Marketing notifications:** настоящий переключатель Enabled/Disabled.
  Сохраняется только предпочтение; уведомления не отправляются.
- **Saved Items:** избранные игры из общего каталога и запланированные просмотры.
  Пустые списки имеют пояснение. Refresh перечитывает данные; изменения
  localStorage в другой вкладке обновляют списки автоматически.
- При недоступном localStorage профиль и настройки работают до перезагрузки,
  а интерфейс сообщает, что сохранение недоступно. Повреждённый JSON
  обрабатывается без падения скриптов профиля и темы.

## Файлы и объяснение для защиты

| Файл | Что объяснять |
| --- | --- |
| `profile.html` | Разметка формы, подписи полей, места для ошибок и Saved Items |
| `assets/js/profile.js` | Валидация, события, изменение профиля и построение списков |
| `assets/js/shared.js` | Ключи хранения, чтение/запись JSON, общая тема |
| `assets/css/profile-extra.css` | Стили формы и сохранённых записей |
| `assets/css/shared.css` | Светлая тема и общая кнопка |
| `assets/js/sports-data.js` | Добавленный при интеграции отсутствовавший файл данных для существующего `sports.js` |

Путь сохранения профиля: `submit` → `preventDefault()` → `validateField()`
для каждого поля → объект `profile` → `saveStorage()` → `showProfile()`.
`validateField()` возвращает `true` или `false`, чтобы обработчик решил,
можно ли сохранять форму. `setError()` меняет текст, класс `is-invalid`
и атрибут `aria-invalid`.

`readStorage(key, fallback)` читает строку из localStorage и преобразует JSON
в значение. При ошибке возвращает запасное значение. `saveStorage(key, value)`
преобразует значение в JSON и возвращает результат сохранения.

`renderSavedItems()` очищает старые списки через `replaceChildren()`,
обходит массивы с `forEach()` и добавляет `li` через `createElement()` и `append()`.
`textContent` отображает пользовательские строки как текст.
Цикл `for...of` используется для проверки полей и подключения обработчиков.
События этой части: `DOMContentLoaded`, `click`, `input`, `change`, `submit`, `storage`.

## Общий формат localStorage

Все значения записываются через `JSON.stringify()`. Ключи определены в
`storageKeys` в `shared.js`, который подключён раньше остальных скриптов.

| Ключ | Значение после JSON.parse |
| --- | --- |
| `cyberWinProfile` | `{ name: "Muba", email: "muba@example.com", country: "Kazakhstan" }` |
| `cyberWinTheme` | `"dark"` или `"light"` |
| `cyberWinNotifications` | `true` или `false` |
| `cyberWinFavorites` | Массив числовых ID из `catalog-data.js`, например `[1, 3]` |
| `cyberWinSchedule` | Массив `{ match, sport, time }`, пример ниже |

```js
[
  {
    match: "Arsenal vs Chelsea",
    sport: "Football",
    time: "2027-12-01T18:00"
  }
]
```

Время расписания — локальное время пользователя. Файл `sports-data.js`
передаёт `storageKeys.schedule` существующему `sports.js` через
`window.cyberWinSports.storageKey`. Поэтому записи спортивной формы
сразу доступны в профиле. Статические примеры из таблицы Sports не считаются
сохранёнными записями.

Участнику Casino нужно сохранять числовые ID в `storageKeys.favorites`.
Сейчас кнопки избранного в `casino.js` ещё нет. Профиль уже читает этот формат,
но до реализации кнопок его список игр остаётся пустым.

## Как проверить

1. В Profile нажмите Edit Profile. Введите имя `ab`, email `wrong`,
   оставьте страну пустой и нажмите Save profile. Должны появиться три ошибки,
   данные не должны сохраниться, страница не должна перезагрузиться.
2. Введите `Muba`, `muba@example.com`, выберите Kazakhstan. Сохраните:
   заголовок и контактные данные должны обновиться, появится сообщение об успехе.
   Перезагрузите страницу и проверьте сохранение.
3. Откройте форму, измените имя и нажмите Cancel. Старые данные должны остаться.
4. Переключите Marketing notifications, затем перезагрузите страницу.
   Состояние должно сохраниться.
5. Переключите Light mode и пройдите по всем пяти ссылкам меню.
   Проверьте текст, формы и карточки. Вернитесь к Dark mode.
6. На Sports заполните форму Match schedule, выбрав будущую дату.
   После отправки откройте Profile: запись должна появиться в Planned viewings.
7. Для отдельной проверки чтения избранного выполните в консоли браузера:

   ```js
   localStorage.setItem("cyberWinFavorites", JSON.stringify([1, 3]));
   ```

   Нажмите Refresh saved items: появятся MERRAMUN и Zeus Overdrive.
   Удалите только тестовые данные через
   `localStorage.removeItem("cyberWinFavorites")` и снова нажмите Refresh.
8. Откройте Profile в двух вкладках. Измените тему или уведомления в одной:
   другая должна обновиться. Не используйте реальные личные данные.
9. Проверьте клавиатуру: Tab, Enter на кнопках, Space на переключателе.
   На ширине 375 px форма и Saved Items должны помещаться в одну колонку.
10. Проверьте прежние функции: поиск и категории Casino, поиск и More info
    в Live Casino, все вкладки Sports и Esports. Проверьте консоль браузера.

При разработке части Muba пройдены 69 автоматических проверок DOM и интеграции
в jsdom, синтаксические проверки JavaScript и проверка локальных ссылок.
Визуальная проверка в настоящем браузере остаётся ручным шагом.

## Границы интеграции

Логика `casino.js`, `live-casino-jquery.js` и `assets/js/sports.js` не изменялась.
На чужие HTML-страницы добавлены только подключения общей темы.
Отсутствовавший `sports-data.js` добавлен с демонстрационными данными,
совместимыми с готовым спортивным скриптом.

До полной сдачи всей команды ещё нужно завершить задачи других участников:

Профиль обеспечивает отдельную полноценную JavaScript-валидацию.
